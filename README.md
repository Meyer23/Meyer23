## 💼 Experiencia Profesional

### 🏦 Desarrollador Backend Senior — ITAE S.A. (Solar Banco)
**Asunción, Paraguay · Abril 2024 – Actualidad**

Desarrollo de microservicios bancarios críticos para una institución financiera paraguaya.

- Liderazgo en la migración del sistema de notificaciones a **Apache Kafka**, implementando arquitectura event-driven para procesamiento en tiempo real de operaciones bancarias críticas
- Implementación de patrones de resiliencia (**circuit breaker, retry, timeout**) con Spring Boot para prevenir fallas en cascada y mantener alta disponibilidad en producción
- Participación clave en la renovación completa de banca web y app móvil a nivel de microservicios, mejorando tiempos de respuesta y experiencia del cliente
- Integración con múltiples APIs financieras de terceros:
  - **Bancard** (SOAP)
  - **BCP QR Hub** (ISO 20022)
  - **ClickToPay / JWE** con cifrado RSA-OAEP-256 + AES-256-GCM
- Containerización con **Docker** y orquestación con **Kubernetes** para estandarizar el ciclo de vida de servicios en ambientes productivos
- Desarrollo de librerías internas compartidas (manejo centralizado de excepciones, utilidades comunes) para estandarizar procesos y reducir tiempos de desarrollo entre equipos
- Configuración de pipelines **CI/CD** con GitLab y monitoreo con **Grafana + Prometheus** (vía Micrometer) para observabilidad de microservicios en producción
